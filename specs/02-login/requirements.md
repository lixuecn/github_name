# 02 登录 — 需求

来源：[docs/需求.md](../../docs/需求.md)「功能需求 / 2. 登录」「技术说明」

## 目标

已注册用户可以用「用户名 + 密码」在 Web 端与移动端登录。用户名认证的基础能力（插件、频率限制、错误映射）由 [01-registration](../01-registration/requirements.md) 的 REQ-001 提供。

## 用户

已在 [01-registration](../01-registration/requirements.md) 注册的用户。

## 范围

- 用户名 + 密码登录表单（Web、Native）
- 关闭按邮箱登录的公开入口
- 登录成功后跳转与提示

## 非目标

- 记住我 / 会话时长配置、第三方登录、找回密码、验证码

## 需求

### REQ-001 用户名登录

- REQ-001.01 表单字段：用户名、密码；校验规则同 [01-registration REQ-002.01、REQ-002.02](../01-registration/requirements.md)。
  - 预期：校验不通过时在字段下方显示中文错误，不发起请求。
  - 验收：输入 `ab` 或 7 位密码点击登录，显示错误且无登录请求。
- REQ-001.02 用户名不区分大小写：以 `testuser` 注册的用户，输入 `TestUser` 也能登录。
- REQ-001.03 用户名不存在或密码错误时，统一提示「用户名或密码错误」，不区分具体原因。
  - 验收：错误密码与不存在的用户名两种情况，提示文案完全一致。
- REQ-001.04 登录成功：Web 跳转到 `/dashboard`，移动端停留首页并显示已登录状态，均提示「登录成功」。
- REQ-001.05 提交过程中按钮显示加载状态并禁用。
- REQ-001.06 触发频率限制时提示「请求过于频繁，请稍后再试」。

### REQ-002 关闭邮箱登录

- REQ-002.01 服务端禁用 `/sign-in/email` 端点。
  - 触发：直接调用 `POST /api/auth/sign-in/email`。
  - 预期：返回 404，无法通过占位邮箱登录。
  - 验收：使用已注册用户的占位邮箱与正确密码调用该端点，返回 404 且不下发会话 cookie。

### REQ-003 界面

- REQ-003.01 登录界面全部中文，无邮箱字段与文案；输入框有 label；Web 支持回车提交。
- REQ-003.02 登录与注册界面可互相切换。
  - 验收：Web `/login` 页上点击切换链接可在登录、注册表单间来回切换。
