# 02 Web 端 GitHub 人员管理 — 需求

来源：[docs/需求.md](../../docs/需求.md) §2、§5、§6「Web」。依赖 [01 GitHub 人员后端能力](../01-github-api/requirements.md) 提供的接口与共享校验。

## 目标

管理员在 Web 端按用户名搜索 GitHub 用户，把人员加入系统，并在同一页面对已加入人员进行查看、编辑、同步、删除。

## 用户

- 系统管理员（无需登录）

## 范围

- 页头导航入口与 `/github` 页面
- 搜索区：输入、校验、结果卡片、加入系统
- 列表区：过滤、排序、分页、编辑、同步、删除，以及加载 / 空 / 错误状态
- 响应式布局（桌面表格、窄屏卡片）、浅色 / 深色模式沿用现有主题

## 非目标

- 登录、权限；人员详情页（含搜索结果中的「查看」跳转）
- 服务端逻辑（见 01）；App 端（见 03）

## 需求

### REQ-001 页面入口

- REQ-001.01 页头导航新增「GitHub 人员」链接，指向 `/github`；页面无需登录即可访问。
  - 验收：从首页点击「GitHub 人员」进入 `/github`；直接访问 `/github` 返回 200。

### REQ-002 搜索 GitHub 用户

- REQ-002.01 搜索框带可见 label，输入用户名后按回车或点击「搜索」发起查询。
  - 业务规则：输入去除首尾空格后为空时不请求；格式校验同 [01 REQ-002.01](../01-github-api/requirements.md)，不合法时在输入框下方提示「GitHub 用户名格式不正确」且不请求。
  - 验收：输入 `-abc` 回车，显示格式错误且无网络请求；输入空格回车无任何请求。
- REQ-002.02 结果卡片展示：头像、昵称、用户名、简介、公司、所在地、博客、Twitter、公开仓库数、粉丝数、关注数、GitHub 注册时间（`YYYY-MM-DD`）、主页链接（新窗口打开）；空字段不显示该行。
  - 业务规则：博客仅在 http(s) 链接时渲染为链接（无协议的值补 `https://` 后校验），否则显示纯文本；所有外链 `target="_blank"` 且 `rel="noopener noreferrer"`。
  - 验收：搜索 `torvalds` 显示上述字段；外链属性正确。
- REQ-002.03 状态：查询中显示加载骨架且搜索按钮禁用；用户不存在显示「未找到该 GitHub 用户」；GitHub 限流显示「GitHub 请求过于频繁，请稍后再试」；其他错误显示「查询失败，请稍后重试」。错误在搜索区内展示，不重复弹出全局提示。
  - 验收：搜索不存在的用户名显示对应文案，且页面无重复的 toast。
- REQ-002.04 已在系统中的用户，卡片显示「已添加」标记，不显示「加入系统」按钮。
  - 验收：加入后再次搜索同一用户，显示「已添加」。

### REQ-003 加入系统

- REQ-003.01 结果卡片上有可选的「备注」输入框（≤200 字，显示剩余字数）与「加入系统」按钮。提交中按钮禁用并显示加载；成功后提示「添加成功」、卡片变为「已添加」、列表立即刷新。
  - 异常：重复添加提示「该用户已在系统中」；其他错误以服务端返回文案提示。
  - 验收：点击加入后列表首行出现该用户；数据库新增一条记录。

### REQ-004 人员列表

- REQ-004.01 每项展示：头像、昵称（为空显示 login）、`@login`、备注、标签、粉丝数、公开仓库数、最后同步时间（相对时间）。数值缩写（1.2k、3.4M）。
  - 验收：列表行内容与数据库一致。
- REQ-004.02 关键字过滤（匹配用户名 / 昵称 / 备注），输入防抖 300ms；排序下拉：最新添加（默认）、粉丝最多、仓库最多；切换过滤或排序时回到第一页。
  - 验收：输入关键字后只显示匹配项；切换排序后顺序正确。
- REQ-004.03 分页：每页 20 条，提供「上一页」「下一页」及「共 N 人」；无上一页 / 下一页时对应按钮禁用。
  - 验收：25 条数据时第 1 页 20 条，下一页 5 条，再返回上一页回到前 20 条。
- REQ-004.04 状态：加载中显示骨架；无数据显示「还没有添加任何 GitHub 用户，先在上方搜索一个吧」；有关键字但无结果显示「没有匹配的人员」；加载失败显示错误与「重试」按钮。
  - 验收：清空数据库后显示空状态文案。
- REQ-004.05 布局：宽度 ≥768px 用表格，窄屏用卡片，均不出现横向滚动。
  - 验收：375px 宽度下无横向滚动条。

### REQ-005 编辑

- REQ-005.01 每项有「编辑」操作，打开弹窗修改备注（≤200 字）与标签（输入后回车或逗号添加，≤5 个、每个 ≤20 字、去重，可删除单个标签）。保存中按钮禁用；成功提示「保存成功」并关闭弹窗、刷新列表。
  - 异常：超限时在弹窗内提示且不提交；记录已不存在时提示「该人员不存在」并刷新列表。
  - 验收：修改后刷新页面，备注与标签仍为新值。

### REQ-006 从 GitHub 刷新

- REQ-006.01 每项有「从 GitHub 刷新」操作，进行中该项操作禁用；成功提示「已同步」并刷新列表（同步时间更新）。
  - 异常：账号已不存在提示「该 GitHub 用户已不存在」，记录保留；限流 / 其他错误以服务端文案提示。
  - 验收：刷新后「最后同步时间」变为「刚刚」，备注与标签不变。

### REQ-007 删除

- REQ-007.01 每项有「删除」操作，弹出确认框「确定将 {login} 从系统中移除吗？」，确认后删除，提示「已删除」并刷新列表；取消则不做任何事。当前页删空且有上一页时回到上一页。
  - 验收：确认后该记录从列表与数据库消失；取消后记录仍在。

### REQ-008 体验与可访问性

- REQ-008.01 所有文案中文；输入框有关联 label；图标按钮有 `aria-label`；弹窗可用键盘操作（Esc 关闭、焦点在弹窗内）。
  - 验收：浏览器测试中通过 label / aria-label 定位到全部交互元素。
