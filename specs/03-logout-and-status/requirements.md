# 03 退出登录与登录状态展示 — 需求

来源：[docs/需求.md](../../docs/需求.md)「功能需求 / 3. 退出登录」「5. 登录状态展示」「验收标准」（保持登录状态）

## 目标

用户能直观看到自己是否已登录，能随时退出登录，且登录状态在刷新页面或重启 App 后保持。会话由 [01-registration](../01-registration/requirements.md) / [02-login](../02-login/requirements.md) 建立。

## 用户

Web 与移动端的所有用户（已登录与未登录）。

## 范围

- Web 页头登录状态与用户菜单
- `/dashboard` 欢迎信息与受保护数据展示
- Native 首页登录状态卡片
- Web 与 Native 的退出登录
- 会话持久化

## 非目标

- 多设备会话管理、强制下线、会话过期时长调整

## 需求

### REQ-001 Web 页头登录状态

- REQ-001.01 未登录时页头显示「登录」按钮，点击进入 `/login`。
- REQ-001.02 已登录时页头显示用户名按钮，点击展开菜单，菜单含「我的账户」标题与「退出登录」项，不显示邮箱。
- REQ-001.03 会话加载中显示占位骨架，不闪现「登录」按钮。
- REQ-001.04 页头导航文案为中文（「首页」「控制台」）。
  - 验收：登录前后页头分别显示「登录」与用户名；菜单中无 `@` 字符。

### REQ-002 Dashboard 展示

- REQ-002.01 `/dashboard` 显示「欢迎，{用户名}」。
- REQ-002.02 调用 `privateData` 接口并展示返回的受保护数据（中文消息）。
  - 验收：登录后访问 `/dashboard` 可见欢迎语与接口返回的消息。

### REQ-003 退出登录

- REQ-003.01 Web：点击用户菜单「退出登录」，清除会话并跳转首页，页头恢复「登录」按钮。
- REQ-003.02 Native：已登录时首页卡片显示「欢迎，{用户名}」与「退出登录」按钮（不显示邮箱）；点击后清除会话，首页恢复登录 / 注册表单。
- REQ-003.03 退出失败（网络错误）时提示「退出失败，请稍后再试」，保持当前状态。
  - 验收：退出后刷新页面仍为未登录；退出后访问 `/dashboard` 的行为见 [04-access-control](../04-access-control/requirements.md)。

### REQ-004 会话持久化

- REQ-004.01 Web 刷新页面后保持登录状态（httpOnly cookie）。
- REQ-004.02 Native 重启 App 后保持登录状态（`expo-secure-store`）。
  - 验收：登录后刷新 `/dashboard`，仍显示欢迎语；App 杀进程重开后首页仍显示已登录卡片。

## 待确认项

- Q-001（假设）Native 已登录卡片中原先显示邮箱的位置改为显示用户名，不再显示其他字段。
